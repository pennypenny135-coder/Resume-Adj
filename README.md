# 履歷調校器 · Resume, Cover Letter & Portfolio Tailorer

一個 **100% 純前端、本地處理** 的求職文件管理工具：用一份「母版素材庫」衍生出多個針對不同公司／職位的履歷、求職信與作品集版本，並以本地關鍵字比對協助你針對 JD 微調。

> **私隱原則**：沒有後端、沒有外部 API、沒有 AI 服務、沒有追蹤。所有資料只存在你瀏覽器的 `localStorage`；列印、匯出、分享完全由你決定，不會自動產生任何公開連結或上傳雲端。

## 功能總覽

| 分頁 | 說明 |
| --- | --- |
| **版本管理** | 基於母版新增／空白版本、複製、重新命名、備註、申請狀態（草稿／已投遞／面試中／已獲 Offer／未成功／已封存）、刪除、搜尋與狀態篩選；每張卡片顯示啟用數量與 JD 覆蓋率 |
| **母版資料庫** | 個人資料（姓名、職銜、聯絡方式、LinkedIn / GitHub / 作品集）、工作經驗（含標籤與多條 Bullet）、項目／作品集、技能分類、學歷／證書、求職信段落庫 |
| **版本內容** | 為「目前版本」勾選經驗／Bullet／項目／技能／學歷；調整順序；**局部覆寫**職銜、簡介、單條 Bullet、項目摘要（不影響母版，可一鍵還原）；切換顯示哪些聯絡方式；右側即時預覽 |
| **JD 比對** | 貼上 JD → 本地詞頻與詞典比對 → 顯示 JD 關鍵字、已涵蓋／未涵蓋、覆蓋率；從母版素材庫給出可一鍵加入的補強建議；可「依 JD 相關度重排」Bullet 與經驗 |
| **履歷排版匯出** | 單欄／雙欄、字體大小、頁邊距、A4／Letter、黑體／明體、中英標題、顯示／隱藏區塊；列印／另存 PDF、匯出 `.md`、`.txt`、複製文字；預計頁數及分頁參考線 |
| **求職信** | 公司／職位／收件人變數（`{{company}}` `{{role}}` `{{manager}}` `{{name}}` `{{title}}` `{{date}}`）、段落組合與排序、版本內覆寫；複製、`.md`、`.txt`、列印 |
| **作品集** | 按標籤（任一／同時符合）篩選項目；可只看目前版本已啟用項目；匯出 `.md`／`.json`／列印 |
| **差異對比** | 母版 vs 版本、版本 vs 版本：新增／移除／修改／順序調整，文字修改以詞級（中文逐字）標示 |
| **資料與備份** | 完整 JSON 備份／還原、載入示範資料、切換空白個人資料、**一鍵清空所有資料**、儲存狀態 |

頂部固定顯示：目前版本、啟用的經驗／Bullet／項目／技能數、JD 關鍵字覆蓋率、最後儲存時間。

首次打開會載入一組虛構的**示範資料**（3 個版本：前端工程師、產品經理、前端組長），可直接體驗；頂部橫幅可一鍵切換為空白個人資料。

## 技術棧

- **React 19** + **TypeScript**
- **Vite 7**（`vite-plugin-singlefile` 把產物打包成單一 `dist/index.html`，可直接雙擊離線開啟）
- **Tailwind CSS 4**
- `clsx` + `tailwind-merge`（class 合併）
- 沒有其他執行時依賴：不使用路由、狀態管理庫、PDF 庫或任何網絡請求

## 架構

```
src/
├─ types.ts              # 全部資料型別（Master、Version、Layout…）
├─ sampleData.ts         # 示範母版與 3 個示範版本
├─ store.tsx             # React Context：狀態、持久化、版本操作、衍生資料（resolved / analysis）
├─ lib/
│  ├─ resolve.ts         # 「母版 + 版本設定」→ 最終履歷／求職信內容；Markdown / 純文字輸出
│  ├─ keywords.ts        # 本地 JD 關鍵字分析（詞典＋別名＋素材庫詞彙＋高頻詞）與補強建議
│  ├─ diff.ts            # 版本差異（扁平化比對＋詞級 LCS）
│  ├─ portfolio.ts       # 作品集篩選與匯出
│  ├─ storage.ts         # localStorage 讀寫、備份匯出／匯入、資料清洗（sanitize）
│  ├─ versions.ts        # 建立／複製版本、預設版面
│  └─ util.ts            # 下載、複製、列印、檔名處理…
├─ components/           # UI 元件、文件預覽（Resume/Cover/Portfolio）、回饋（Toast / Confirm）
└─ tabs/                 # 九個功能分頁
```

### 資料模型：母版 + 引用

- **Master**（母版）保存所有素材與預設文字。
- **Version**（版本）**只保存「引用」與「覆寫」**：啟用的經驗 ID（有序）、每段經驗啟用的 Bullet ID（有序）、項目 ID、技能選取、學歷 ID，以及 `overrides`（職銜、簡介、Bullet 文字、項目摘要）。
- 顯示時由 `resolveResume()` 合併出最終內容。因此：
  - 版本內的微調不會弄亂母版；
  - 母版刪除某項後，版本會自動略過失效的引用而不會報錯；
  - 母版新增的素材不會自動進入既有版本（避免意外改動已投遞的版本）。

### JD 關鍵字比對（純文字演算）

1. 內置約 130 組技能／工具／軟技能詞典，含中英別名（如 前端＝Frontend、k8s＝Kubernetes、專案管理＝Project Management）。
2. 加入你母版中的技能與標籤作為個人詞彙。
3. 統計 JD 中的英文高頻詞（過濾停用字）與中文 2–4 字詞組（過濾常見虛詞並去除被較長詞包含的片段）。
4. 比對時對拉丁字詞做詞界檢查（`java` 不會誤中 `javascript`；`c++`、`.net` 等符號詞可用）。
5. 覆蓋率 ＝ 已出現在目前版本文字（職銜、簡介、Bullet、項目、技能、學歷；尊重區塊顯示設定）的 JD 關鍵字 ÷ JD 關鍵字總數（上限 45 個）。

> 這是詞面比對，不是語意理解：建議把它當作「檢查清單」，不要為了湊覆蓋率而加入你實際不具備的技能。

### 列印與 PDF

列印內容會渲染到 `<body>` 下獨立的 `#print-portal`，列印時隱藏整個 App（`@media print`），避免被捲動容器裁切；頁邊距與紙張以動態 `@page` 規則套用。請在瀏覽器列印視窗選擇「另存為 PDF」，並關閉「頁首及頁尾」。預覽中的紅色虛線為大約分頁位置。

## 本地儲存機制

- 資料存於 `localStorage`，key：`resume-tailorer:v1`，內容 `{ data, savedAt }`。
- 每次編輯後約 350ms 防抖寫入；離開頁面（`pagehide` / `beforeunload`）時會立即補寫。
- 載入時經 `sanitizeData()` 清洗：缺漏欄位補預設值、型別錯誤略過、重複 ID 修正、保證至少有一個版本，即使備份被手動編輯過也不會令介面崩潰。
- 若瀏覽器儲存空間已滿或被停用，頂部會顯示「儲存失敗」，請立即匯出 JSON 備份。
- **備份**：「資料與備份」→ 匯出完整 JSON；匯入前會要求確認並以備份取代目前資料。
- **清空**：「一鍵清空所有資料」會移除 `localStorage` 記錄並重置為空白工作區（共用電腦使用後建議執行）。清空後重新整理會再次載入示範資料，其中不含任何你的個人資料。
- 資料只屬於當前瀏覽器 profile：換瀏覽器、無痕視窗或清除網站資料後不會保留，請定期備份。

## 穩定性考量

- 中英文混排：文件預覽使用 `overflow-wrap: anywhere` 與 CJK 字體 fallback；差異對比中文逐字、英文逐詞。
- 空白欄位：空公司／職位／時間／連結不會產生多餘分隔符；空 Bullet 不輸出。
- 特殊符號：全部以 React 文字節點渲染（不使用 `innerHTML`），Markdown 匯出不會破壞原文；`.txt` 匯出附 UTF-8 BOM，避免 Windows 記事本亂碼。
- 大量版本與標籤：版本列表支援搜尋及狀態篩選；標籤輸入支援 IME 組字（組字中按 Enter 不會誤提交）。

## 本地啟動與建置

需要 Node.js 18+。

```bash
npm install
npm run dev      # 開發伺服器（預設 http://localhost:5173）
npm run build    # 輸出到 dist/index.html（單一檔案，可離線開啟）
npm run preview  # 預覽建置結果
```

建置後的 `dist/index.html` 不需要任何伺服器，直接用瀏覽器開啟即可使用（`file://` 下 localStorage 亦可運作，但不同開啟方式／網址會各自擁有獨立資料）。
